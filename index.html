WebDAQ — data acquisition for the LUNA experiment

WebDAQ reads the CAEN digitizers, writes the data, shows the spectra while they fill, records what the beam was doing and says something when a board stops. This manual is written for the person on shift; the later chapters are for whoever has to change the system.

The same material is available as a single PDF, built from manual/ in the repository.
